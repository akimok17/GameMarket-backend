# Проверка Order Room

1. Войти продавцом и покупателем в двух разных браузерах/профилях.
2. Покупатель создаёт и оплачивает заказ.
3. После оплаты браузер должен перейти на `/order/<id>`.
4. Оба участника открывают страницу — статус online должен меняться realtime.
5. Отправить сообщения с обеих сторон; проверить «печатает…» и `✓✓` после прочтения.
6. Отправить PNG/JPG; проверить, что без Authorization URL картинки возвращает 401.
7. Для ручного товара продавец нажимает «Передать товар».
8. Покупатель видит защищённый блок данных выдачи.
9. Покупатель подтверждает получение — продавцу начисляется `seller_earnings`.
10. После завершения покупатель оставляет отзыв.
11. В другом тестовом заказе открыть спор и проверить, что автозавершение выключено.
12. Нажать «Помощь по заказу» — форма поддержки должна открыться с заполненным `order_id`.
13. Проверить timeline: создание → оплата → выдача → подтверждение/спор → отзыв.
